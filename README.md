# IBD Scientific Engagement Intelligence (demo)

Clickable discovery demo in the visual style of the Takeda IBD Intelligence Lovable app. One shared live data store drives every page: Executive dashboard, HCP explorer, Live intelligence feed, Engagement signals, AI engagement engine (overview + live dynamic scoring: decile view, Ask AI, data sources, architecture), Results & recommendations, Influencer leaderboard, Emerging influencers, Command center and HCP profiles.

All physician records and signals are synthetic.
